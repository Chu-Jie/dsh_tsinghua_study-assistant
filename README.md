# 学习辅助 / dsh-study-assistant · v1.0

> 一个面向大学生的 DSH（DeepSeek Harness）插件：把**课表、DDL、成绩与 GPA、课程资料、知识点网络、学习记录**收进一个面板，
> 再在里面长出一个**只活在这个面板里的学习助手**——能答疑、能改掌握度、能记住你在学什么。
> 同一份数据同时暴露成会话工具与一条只监听本机回环的 HTTP 接口。

写它的动机很朴素：一个学期的信息散在教务系统、网络学堂、课件 PDF、教师群里，
**每周真正要回答的问题只有三个**——今天上什么课、哪些 DDL 快到了、这门课我到底掌握了多少。
v1.0 之前，这三件事只是「看得见」；v1.0 之后，面板里多了一个能读着这些数据跟你说话的东西。

- 插件 id / 接口前缀：`study-assistant` / `/api/study-assistant`
- 面板名（中文）：**大学生学习辅助系统**；侧栏标签「学习辅助」
- 仓库：<https://github.com/Chu-Jie/dsh_tsinghua_study-assistant>
- 许可：MIT；**运行时零 npm 依赖**（唯一第三方代码是随仓库携带的 PDF.js，见 `THIRD_PARTY_NOTICES.md`）
- Node：`>= 22`

---

## 一、它是什么

一句话：**把「学期」这一件事的全部数据放在一个可读、可手改、能进 git 的目录里，然后用一个面板和一条接口去用它。**

三条设计主线，决定了它长成现在这样：

| 主线 | 具体做法 |
|---|---|
| **数据是你自己的** | 16 份人类可读的 JSON，UTF-8、无 BOM、能直接改。插件只读写 `dataDir` 这一个目录，不埋数据库 |
| **一份真源，两个使用者** | 面板与 agent 会话读写同一份数据；页面上看到的和会话里改的永远是同一份 |
| **助手住在面板里** | 学习助手不是桌面宠物、不开机自启、不占独立窗口：它只是面板内的一个浮层，关掉面板即消失 |

## 二、它能做什么

| 能力 | 说明 |
|---|---|
| **八页签主面板** | 今日 / 课表 / DDL / 成绩 / 资料 / 知识点 / 记录 / 设置。样式只吃 DSH 主题令牌，跟着明暗主题走；面板本身可拖拽缩放、可切深浅色 |
| **课表与教学周** | 按学期配置周次，自动换算「第几周 / 单双周 / 今天第几节」 |
| **DDL 汇总** | 任务带截止时间、紧急度、完成态；按学科、状态、紧急度筛选与快捷录入 |
| **成绩与 GPA** | 4.0 制加权 / 5.0 制加权两种制式，可设目标 GPA 反推「还需要考多少」 |
| **网络学堂同步** | 手动触发：粘一次 Cookie → 预览 → 导入，把平台作业变成 DDL；只做单向状态升级，后台不轮询 |
| **课堂听课提醒** | 课堂音频切片喂语音识别，命中本人姓名（含可配置的多种写法）时提醒，并把课堂笔记落到学科目录 |
| **课程资料检索** | 为教材/课件/作业建索引，按「学科 → 文件夹 → 文件」折叠成树，按页读正文（扫描件走 OCR 产物） |
| **统一阅读面** | 资料页与知识点页共用同一个阅读卡片与同一套缩放：`A−`/`A+`/`100%`/`适应窗口`，倍率 0.75～1.75 |
| **知识点网络** | 候选 → 织网 → 节点（掌握度 / 重点 / 大纲挂靠 / 证据），可导出成笔记镜像 |
| **掌握度四档** | 未学 / 学过 / 熟练 / 精通。**算法按访问次数、批注、累计时长自动推进**；人工改过的记 `manual`，算法不再覆盖；只升不降 |
| **学习助手（v1.0 主角）** | 面板内浮层聊天：把看不懂的题干复制粘贴进去就能问；回答带「当前界面」上下文与「你在学什么」的画像；多会话可新建/改名/归档并落盘；右栏可选模型；专注学习模式切「学习搭子」人设 |
| **助手能改数据，但要你点头** | 「把某知识点设为熟练」这类**命令**先回一条预览（改哪个、从几级到几级），确认后才落库；一批知识点可批量确认。**日程与 DDL 同理**：说一句话就列改动清单，确认才写，删除要按两次 |
| **今日日程** | 一张卡只放「今天/明天的日程 + 逾期和今明两天到期的 DDL」——课程不再重复摆（看课去「课表」），更迟的 DDL 指路「DDL」页签 |
| **学习记录时间线** | 「记录」页签把「读过 / 批注过 / 标了什么知识点」按时间摊开，每条带来源；不埋点、不编造事件 |
| **批注** | 选中正文即浮出气泡：批注 / 高亮 / 插入段落，失焦即存；正文内联标记可点改点删 |
| **提交件归档** | 扫描各学科 `提交文件/`，**只有文件名同时含姓名与学号**才把任务归档；交付解答不算归档 |
| **全量备份与恢复** | 16 份 JSON 打成一个带 sha256 校验和的包；恢复先验包再逐份校验，任一份不合法整批不写 |
| **会话工具** | `study_status`（数据健康）、`study_overview`（当前学期 / 今日课程 / 临近 DDL / GPA） |

## 三、v1.0 是什么版本

v1.0 不是一个新写的插件，而是**把 2026-10 到 11 月的九轮「学习助手」迭代收口**（内部代号 v2-A ～ v2-J），并清理掉上半年的实验性代码：

| 轮次 | 落地的东西 |
|---|---|
| v2-A | 助手能看到「当前界面」（正在看哪门课、哪个知识点、哪个页签） |
| v2-B / v2-B2 | 掌握度自动计算 + 学习行为记录（第 16 份文档）；命令式改掌握度先预览；支持「今天学过的 / 整章 / 同理」批量改 |
| v2-C | 多会话落盘（`学习台/助手会话/`）+ 上下文压缩；会话可新建 / 改名 / 归档 |
| v2-D | 「懂我画像」：把「我是谁、在学什么、学到哪」压成一段隐式提示，只进 system，不进响应与日志 |
| v2-E | 专注学习模式：切「学习搭子」人设，跟着专注阅读一起开关 |
| v2-F | 浮层气泡排版（公式、列表在窄气泡里也能读） |
| v2-G | 面板自管一套配色 + 深浅主题按钮 + 用户拖过的面板大小（摆脱宿主半透明令牌） |
| v2-H | 专注阅读三栏布局：正文列宽与右栏列宽可拖，拖过的宽度跨会话记住 |
| v2-J | 右栏「选模型」下拉（服务端转网关 `/models`，前端不直连、不见密钥） |

同时 v1.0 定版前删掉了旧的「三档讲解 + 面板内多轮对话」实验线：面板不再自建对话系统，讲解走 `资料分析.json`，对话统一交给学习助手。

## 四、安装

### 前置

- DSH 桌面端或等价宿主（`ctx.webServer` / `ctx.tools` / `ctx.effect` 可用），Node `>= 22`。
- 不需要 `npm install`：仓库没有任何运行时依赖，`tests/` 用 Node 内置 `node:test`。

### 方式一：`link:` 装进 profile（开发时推荐）

把仓库直接链进你在用的 DSH profile，改源码后**重启 DSH + 刷新页面**即生效，没有构建步骤：

```bash
# 以 DSH profile 目录为准，示例路径
cd <DSH profile 目录>
npm install "link:<本仓库绝对路径>"
```

profile 的插件清单里会出现一条 `dsh-study-assistant` 指向本仓库（`package.json` 的 `name`，也是 `cordis.patch.yml` 里 `name` 的取值）。

### 方式二：用 `cordis.patch.yml` 声明装载

仓库自带 `cordis.patch.yml`，把插件插进 profile 的配置链：

```yaml
- insert:
    - id: study-assistant
      name: 'dsh-study-assistant'
      config:
        locale: zh
        gpaMode: 4.0-weighted
        backupKeep: 10
        dataDir: '$HOME/study-assistant-data'
```

> 本插件的所有路由都挂在**一条** `kind: 'prefix'` 的 `/api/study-assistant` 下，
> 不需要、也不要再注册 `kind: 'exact'` 的子路径。

### 装完必须重启一次

运行中的宿主进程持有旧的 ESM 模块代，**不会**热重载插件主体。
重启后左侧栏出现「学习辅助」入口，会话里出现 `study_status` / `study_overview` 两个工具。

确认装对了：

```bash
curl "http://127.0.0.1:<端口>/api/study-assistant/health"
# {"ok":true,"healthy":true,"docs":{...16 份全 ok...},"dataDir":"..."}
```

## 五、配置

全部配置项都通过 DSH 的插件配置传入（`Config` 手写了一份同步校验 schema，不引入 schemastery）。
**九项，每一项都有默认值，装完零配置即可跑**：

| 键 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `dataDir` | string | `$HOME/study-assistant-data` | 数据目录（绝对路径）。插件**只读写这个目录**。默认由用户主目录推导，换机器不需要改源码 |
| `backupKeep` | number | `10` | 每份数据文件保留几份轮转备份 |
| `locale` | string | `zh` | 界面语言，枚举 `zh` / `en` |
| `gpaMode` | string | `4.0-weighted` | 绩点制式，枚举 `4.0-weighted` / `5.0-weighted` |
| `studentName` | string | `示例同学` | **必须改成你自己的名字**。听课提醒靠它做点名匹配；学习助手的学习画像也用它 |
| `studentNameVariants` | string | 空 | 姓名的其他写法，顿号/逗号/空格分隔（同音字、绰号）。语音转写命中这些写法也算叫到你 |
| `studentId` | string | 空 | 学号。提交件归档只认「文件名同时含姓名与学号」的文件；**留空＝整个归档扫描不启用** |
| `workspaceRoot` | string | 空 | 作业工作区根目录（含各学科目录）；留空时自动取 `dataDir` 的父目录 |
| `recordingDir` | string | 空 | 腾讯会议录音笔的录像根目录（每场次一个子目录）；**留空＝不启用录音导入** |

举个听课提醒的例子：`studentName: 李雷` + `studentNameVariants: 雷子、小李`，
则语音转写出现「李雷」「雷子」「小李」任一写法都算叫到你（按原文匹配，不解释正则元字符）。

## 六、数据目录

插件把学习数据写成 **16 份**人类可读、可手改、能进 git 的 JSON（都在 `dataDir` 下）：

```
<dataDir>/
├─ 学期.json          学期与教学周（term）
├─ 课程.json          课程（courses）
├─ 任务.json          DDL 任务（tasks）
├─ 成绩.json          成绩与 GPA 规则（grades）
├─ 作业.json          作业流台账：来源文件指纹、题数、最近一次生成的模型与时间
├─ 资料索引.json      教材/课件/作业的索引（只读）
├─ 题目.json          从作业里切出来的题（只读）
├─ 知识点候选.json     织网前的候选知识点（只读）
├─ 知识点网络.json     知识点节点 + 掌握度 / 重点 / 证据（可 mutate，唯一掌握度真源）
├─ 知识点大纲.json     教材目录骨架：章 / 节 / 小节（只读）
├─ 资料分析.json      内容库：详解 / 比方 / 公式 / 易错 / 例题（只读，会到 MB 级）
├─ 批注.json          批注 / 高亮 / 插入段落（annotations）
├─ 知识映射.json      知识点与资料页的对应（knowledgeMap）
├─ 日程.json          日程（schedule）
├─ 要闻.json          要闻（news）
├─ 学习行为.json      第 16 份：每节点访问次数 / 最后学习时间 / 累计时长，掌握度据此推算
├─ 助手会话/          学习助手的多会话落盘（每会话一文件 + 可重建的 索引.json）
├─ 学习记录/          旁挂：阅读位置 / 学习时长（不进 /state、不进备份、不进 DOC_KEYS）
├─ 讲解缓存/          旧「三档讲解」的缓存 md（v1.0 起只读，面板已无入口）
├─ 知识画布/          kp-notes 镜像导出（只读视图，可随时重建）
└─ 备份/              写入前的轮转备份
```

五条口径，写在前面免得被当成疏漏：

1. **身份与内容分家**——`知识点网络.json` 存「有哪些知识点、掌握到什么程度」，`资料分析.json` 存「这个知识点讲了什么」。
   后者会到 MB 级，混在一起会让每次 `/state` 都变慢。
2. **掌握度只有一个真源**——就是 `知识点网络.json` 的 `mastery`（0 未学 / 1 学过 / 2 熟练 / 3 精通）。
   `学习行为.json` 只记行为，面板统计、复习提醒、导出全读 `mastery`，不存在第二套口径。
3. **谁说了算**——人改的记 `masterySource: 'manual'`，算法从此跳过这个节点；算法算的记 `auto`，下次还能继续推进。
   **不自动降级**，只会往上补。
4. **凭据不在里面**——网络学堂的 Cookie 存在单独的 `网络学堂.json`，**刻意不在 16 份白名单里**：
   不进 `/state`、不进备份包、不被 `/reset-doc` 触碰。账号密码另存本机 `.learn-credential.json`。
5. **半白名单**——`知识点大纲.json`、`资料分析.json` 能读能备份，但**故意不给 `/mutate` 路由**，
   只能由专用工具整份落盘，避免面板把手改的内容冲掉。

`dataDir` 之外，插件只往工作区写少量文件：听课笔记（各学科目录）、`.learn-edge/`（网络学堂专用浏览器 profile）。
**它不会写任何其它位置。**

## 七、学习助手怎么用

1. **打开**：面板里点开学习助手浮层（不占独立窗口，关掉面板就消失）。
2. **问**：把看不懂的题干、讲义段落、报错信息**复制粘贴**进输入框。它知道你现在在哪个页签、哪门课、哪个知识点。
3. **它记得你**：学习画像会告诉它「这学期在学什么、哪几门最难、你已经学到哪」，所以回答不会像搜索引擎。
4. **让它改数据**：说「把卡诺图设为熟练」这类命令，它**先回一条预览**（改哪个节点、从几级到几级），你确认后才写盘；
   一批知识点（「今天学过的都提升一级」）同样先预览再批量落库。
5. **让它改日程和 DDL**：直接说人话就行——「明天下午三点加个日程：交实验报告」「物理实验报告的 DDL 改到 11 月 25 号」
   「把取快递那条日程删掉」。它把这句话翻译成结构化改动，**先列清单给你确认**，你点「确认执行」才落库；
   清单里只要含删除，按钮会变成「再点一次确认删除」——删除永远要按两次。它不会猜日期、也不会动你没提到的字段。
6. **多会话**：一个问题聊完可以归档，下次另起一条；历史落盘在 `学习台/助手会话/`，可导出、可手改。
7. **专注学习模式**：开启后它切成「学习搭子」——少一点客套，多一点「你现在该做什么」。

## 八、试跑：用 `demo-data/` 看一眼

仓库自带一份**完全虚构的样例数据** `demo-data/`（12 份 JSON：2 门示例课 / 5 个任务 / 0 道题 / 4 个知识点节点 / 7 份资料索引），
不含任何真实课程内容、作业或个人信息，想先看界面长什么样、又不想从零录入时用它：

```bash
# 1. 复制到仓库外（别把 dataDir 直接指到仓库里的 demo-data/：面板一写就把样例改了）
cp -r demo-data "$HOME/study-assistant-data"

# 2. 把 dataDir 指向那份副本，重启 DSH、刷新页面
```

想回到干净状态：删掉副本再重启，缺文件时插件按空文档处理，面板照常打开。
样例是**完全虚构**的演示数据，只用来对照字段形状；与任何真实课程或个人无关。

## 十、开发

想在本地改这个东西，只需要知道五件事（细节都在 `docs/开发备忘.md`）。

```
index.js       宿主入口：配置 schema、apply()、注册路由 / 工具 / 定时器
lib/           领域逻辑（core / store / api / mastery / knowledge / learn …）
lib/lecture/   听课提醒：录音切片、ASR、会话、笔记、报告、面板
client.js      随包发布的面板（单文件、自包含）；client.full.js 是可编辑源，同步后出包
vendor/pdfjs/  随仓库携带的 PDF.js（唯一第三方代码）
```

## 十一、边界与免责

- **只面向本机自用**：HTTP 接口只监听宿主自己的回环端口，写请求要求自定义头 `X-Study-Request: 1` 且拒绝跨站来源；
  它不是一个可以暴露到公网的服务。
- **两条 AI 通道，密钥都在本机**：学习助手走**本机 magpie 网关**（默认 `http://127.0.0.1:3425/v1`、模型 `group/wb`，
  可用 `MAGPIE_BASE_URL` / `MAGPIE_MODEL` 覆盖）；听课提醒的转写与总结走 Paratera（模型 `DeepSeek-V4.1-Flash-1017`）。
  两把密钥分别取 `~/.dsh/.credentials.yaml` 的 `refs.MAGPIE_GATEWAY_KEY` 与 `refs.PARATERA_API_KEY`，
  **只在本机读、只经服务端转发，不进前端、不进日志、不进仓库**。没有可用密钥时助手会明确报错，不会静默装作回答。
- **网络学堂同步依赖你自己的登录态**：Cookie / 浏览器 profile 都留在你本机，插件不上传任何凭证。
  平台侧接口不是公开 API，平台改版后同步可能失效——这属于已知风险，不是缺陷承诺。
- **不代替你提交作业**：插件只归档「你自己放进 `提交文件/` 的带姓名学号的提交件」，
  不会创建提交件、也不会因为「生成了答案」就把任务标完成。
- **不做后台轮询**：网络学堂同步、听课分析都是手动触发，避免触发平台反爬与无意义 token 消耗。
- **掌握度是估算，不是评分**：算法只看访问、批注、时长三项行为，它不代表你真的会了；要准就自己改，改了算法不再覆盖。
- 本项目是个人学习工具，与 DeepSeek / 任何学校教务或网络学堂官方无关；使用需自行遵守所在平台的服务条款。
