# 学习辅助 / dsh-study-assistant

> 一个面向大学生的 DSH（DeepSeek Harness）插件：把**课表、DDL、成绩与 GPA、课程资料、知识点网络**收进一个面板，
> 同时把同样的能力暴露成会话工具和一条只监听本机回环的 HTTP 接口。

写它的动机很朴素：一个学期的信息散在教务系统、网络学堂、课件 PDF、教师群里，
**每周真正要回答的问题只有三个**——今天上什么课、哪些 DDL 快到了、这门课我到底掌握了多少。
这个插件把这三件事放在一个界面里，并用同一份数据支撑「让 agent 帮你做作业」这件事。

- 插件 id / 接口前缀：`study-assistant` / `/api/study-assistant`
- 面板名（中文）：**大学生学习辅助系统**；侧栏标签「学习辅助」
- 仓库：<https://github.com/Chu-Jie/dsh_tsinghua_study-assistant>
- 许可：MIT；**运行时零 npm 依赖**（唯一第三方代码是随仓库携带的 PDF.js，见 `THIRD_PARTY_NOTICES.md`）
- Node：`>= 22`

---

## 它能做什么

| 能力 | 说明 |
|---|---|
| 七页签主面板 | 今日 / 课表 / DDL / 成绩 / 资料 / 知识点 / 设置，样式只吃 DSH 主题令牌，跟随明暗主题 |
| 课表与教学周 | 按学期配置周次，自动换算「第几周 / 单双周 / 今天第几节」 |
| DDL 汇总 | 任务带截止时间、紧急度、完成态；支持按学科、状态、紧急度筛选与快捷录入 |
| 成绩与 GPA | 4.0 制加权 / 5.0 制加权两种制式，可设目标 GPA 反推「还需要考多少」 |
| 网络学堂同步 | 手动触发：粘贴一次 Cookie → 预览 → 导入，把平台作业变成 DDL；只做单向状态升级 |
| 课堂听课提醒 | 把课堂音频切片喂给语音识别，命中本人姓名（含可配置的多种写法）时提醒，并把课堂笔记落到学科目录 |
| 课程资料检索 | 为教材/课件/作业建索引，按页读正文（扫描件走 OCR 产物），面板内直接读 |
| 知识点网络 | 候选 → 织网 → 节点（掌握度 / 重点 / 大纲挂靠 / 证据），导出成笔记镜像 |
| 知识点讲解与问答 | 每个知识点可按三种档位生成讲解（助教推导 / 考前速通 / 只给提示），并围绕该节点的证据自带问答 |
| 提交件归档 | 扫描各学科 `提交文件/`，**只有当文件名同时含姓名与学号**才把任务归档；交付解答不算归档 |
| 全量备份与恢复 | 十一份 JSON 打成一个带 sha256 校验和的包，恢复时先验包再逐份校验，任一份不合法整批不写 |
| 会话工具 | `study_status`（数据健康）、`study_overview`（当前学期/今日课程/临近 DDL/GPA） |

页面与接口共用同一套数据层，因此 **agent 在会话里改的和面板上看到的永远是同一份数据**。

## 安装

### 前置

- DSH 桌面端或等价宿主（`ctx.webServer` / `ctx.tools` / `ctx.effect` 可用），Node `>= 22`。
- 不需要 `npm install`：仓库没有任何运行时依赖，`tests/` 用 Node 内置 `node:test`。

### 方式一：`link:` 装进 profile（开发时推荐）

把仓库直接链进你在用的 DSH profile，改源码后**重启 DSH + 刷新页面**即生效，没有构建步骤：

```bash
# 以 DSH profile 目录为准，示例路径
cd <DSH profile 目录>
npm install "link:<本仓库绝对路径>"
```

profile 的插件清单里会出现一条 `dsh-study-assistant` 指向本仓库（`package.json` 的 `name`，也是 `cordis.patch.yml` 里 `name` 的取值）。

### 方式二：用 `cordis.patch.yml` 声明装载

仓库自带 `cordis.patch.yml`，把插件插进 profile 的配置链：

```yaml
- insert:
    - id: study-assistant
      name: 'dsh-study-assistant'
      config:
        locale: zh
        gpaMode: 4.0-weighted
        backupKeep: 10
```

> 本插件的所有路由都挂在**一条** `kind: 'prefix'` 的 `/api/study-assistant` 下，
> 不需要、也不要再注册 `kind: 'exact'` 的子路径。

### 装完必须重启一次

运行中的宿主进程持有旧的 ESM 模块代，**不会**热重载插件主体。
重启后左侧栏出现「学习辅助」入口，会话里出现 `study_status` / `study_overview` 两个工具。

## 配置

全部配置项都通过 DSH 的插件配置传入（`Config` 手写了一份同步校验 schema，不引入 schemastery）。
**九项，每一项都有默认值，装完零配置即可跑**：

| 键 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `dataDir` | string | `$HOME/study-assistant-data` | 数据目录（绝对路径）。插件**只读写这个目录**（外加工作区里的笔记/备份落点，见下）。默认由用户主目录推导，换机器不需要改源码 |
| `backupKeep` | number | `10` | 每份数据文件保留几份轮转备份 |
| `locale` | string | `zh` | 界面语言，枚举 `zh` / `en` |
| `gpaMode` | string | `4.0-weighted` | 绩点制式，枚举 `4.0-weighted` / `5.0-weighted` |
| `studentName` | string | `示例同学` | **必须改成你自己的名字**。听课提醒靠它做点名匹配，写错这个功能等于没用 |
| `studentNameVariants` | string | 空 | 姓名的其他写法，顿号/逗号/空格分隔（同音字、室友起的绰号）。语音转写命中这些写法也算叫到你 |
| `studentId` | string | 空 | 学号。提交件归档只认「文件名同时含姓名与学号」的文件；**留空＝整个归档扫描不启用** |
| `workspaceRoot` | string | 空 | 作业工作区根目录（含各学科目录）；留空时自动取 `dataDir` 的父目录 |
| `recordingDir` | string | 空 | 腾讯会议录音笔的录像根目录（每个场次一个子目录）；**留空＝不启用录音导入** |

举个听课提醒的例子：`studentName: 李雷` + `studentNameVariants: 雷子、小李`，
则语音转写出现「李雷」「雷子」「小李」任一写法都算叫到你（按原文匹配，不解释正则元字符）。

## 数据目录

插件把学习数据写成**十一份人类可读、可手改、能进 git 的 JSON**（`dataDir` 下）：

```
<dataDir>/
├─ 学期.json          学期与教学周（key: term）
├─ 课程.json          课程（key: courses）
├─ 任务.json          DDL 任务（key: tasks）
├─ 成绩.json          成绩与 GPA 规则（key: grades）
├─ 作业.json          作业流台账：来源文件指纹、题数、最近一次生成的模型与时间
├─ 资料索引.json      教材/课件/作业的索引（面板只读）
├─ 题目.json          从作业里切出来的题（面板只读）
├─ 知识点候选.json     织网前的候选知识点（面板只读）
├─ 知识点网络.json     知识点节点 + 掌握度 / 重点 / 证据（可 mutate）
├─ 知识点大纲.json     教材目录骨架：章 / 节 / 小节（面板只读）
├─ 资料分析.json      扫描产物的内容库：详解 / 比方 / 公式 / 易错 / 例题（面板只读）
├─ 学习记录/          旁挂目录：阅读位置 / 对话归档（不进 /state、不进备份、不进 DOC_KEYS）
├─ 讲解缓存/          按「节点-档位」缓存的讲解 md
├─ 知识画布/          kp-notes 镜像导出（只读视图，可随时重建）
└─ 备份/              写入前的轮转备份
```

设计上的三条口径：

1. **身份与内容分家**——`知识点网络.json` 存「有哪些知识点、掌握到什么程度」，`资料分析.json` 存「这个知识点讲了什么」。
   后者会到 MB 级，混在一起会让每次 `/state` 都变慢。
2. **凭据不在里面**——网络学堂的 Cookie 存在单独的 `网络学堂.json`，**刻意不在十一份白名单里**：
   不进 `/state`、不进备份包、不被 `/reset-doc` 触碰。
3. **半白名单**——`知识点大纲.json` 与 `资料分析.json` 能在白名单里（可读、可备份），但**故意不给 `/mutate` 路由**，
   只能由专用工具整份落盘，避免面板把手改的内容冲掉。

`dataDir` 之外，插件只往工作区写少量文件：听课笔记（各学科目录）、`.learn-edge/`（网络学堂专用浏览器 profile）、
作业详情缓存与 `备份/`（都在 `dataDir` 内）。**它不会写任何其它位置。**

## 试跑：用 `demo-data/` 看一眼

仓库自带一份**完全虚构的样例数据** `demo-data/`（12 份 JSON：2 门示例课 / 5 个任务 / 0 道题 / 4 个知识点节点 / 7 份资料索引），不含任何真实课程内容、作业或个人信息，
想先看界面长什么样、又不想从零录入时用它：

```bash
# 1. 复制到仓库外（别把 dataDir 直接指到仓库里的 demo-data/：面板一写就把样例改了）
cp -r demo-data "$HOME/study-assistant-data"

# 2. 把 dataDir 指向那份副本，重启 DSH、刷新页面
```

想回到干净状态：删掉副本再重启，缺文件时插件按空文档处理，面板照常打开。

样例是**完全虚构**的演示数据，只用来对照字段形状；课程、任务、题目、讲解均为示例，与任何真实课程或个人无关。
`demo-data/任务详情.json` 是空占位（`items: []`）：开源仓库不含任何课程平台抓取缓存。

## 开发

### 章讲义（lectures）

`学习台/资料分析.json` 的每门课程可以有可选的 `lectures[]`：按章保存讲义元数据，`styles[]` 是 A/B/C 主风格，`variants[]` 是同一风格的加强版（例如 C2/C3）。讲义正文必须先登记在 `学习台/资料索引.json`，面板点击后复用 `/materials/text` 和教材正文预览器读取。

扫描讲义目录并预览计划：

```bash
node tools/lectures-sync.mjs --course c_digital --data "<学习台数据目录>"
```

确认无误后落盘。工具通过 `store.writeDocument` 写入，带 hash 冲突检测、原子写和 `学习台/备份/` 自动备份：

```bash
node tools/lectures-sync.mjs --course c_digital --data "<学习台数据目录>" --apply
```

知识点页的章标题旁会显示讲义风格按钮，节点详情卡底部有「本章讲义」入口；没有 `lectures[]` 的课程不显示讲义区块。

### 阅读器缩放（字号 / 100% / 适应窗口）

阅读区（专注阅读里的正文栏）只有**一个**倍率 `--sa-read-scale`，挂在 `.sa-reader-pane` 上：

- **基准**是 DSH 设置里的「内容字号」——宿主把它发布成 `body` 上的 `--dsh-content-font-size`（取不到按 16px）。
  所以面板从不去改 DSH 的全局字号，只在这一栏里乘一个倍率。
- **倍率** 0.75～1.75，步长 1/16（16px 基准下正好 1px 一格），存在界面记忆 `readScale` 里，坏值夹回 1。
- 标题、段落、列表、表格、公式、代码块、聊天气泡**全部**用 `em` 或
  `calc(var(--dsh-content-font-size, 16px) * var(--sa-read-scale, 1) * 系数)`，不写死 px：
  详情卡标题是 ×1.375（22/16）、窄面板那档 ×1.25（20/16）、markdown 表格 `0.875em`、`###` 小标题 `0.9375em`、
  跨行公式与讲义一二级标题 `1.0625em`。**改这些字号时别再写回裸 px**——写了就只有正文跟着缩放，标题和表格会「纹丝不动」
  （`tests/client.test.js` 有源码级断言盯着这一点）。
- 专注标题栏三个控件：`A−` / `A+` 按步长调倍率、`100%` 回到倍率 1（＝完全跟随 DSH 内容字号，
  原来那颗叫「重置」，语义含糊且与 100% 重复，已合并）、`适应窗口` 按阅读区可用宽度反算倍率。
- `适应窗口` 的算法（`fitReadScale(可用宽度, 栏宽)`）：栏宽 = 设计行宽 **80ch** 在当前基准字号下折成的像素
  （让浏览器自己量 `ch`，量不到按 1ch≈0.5em 估），倍率 = 可用宽度 ÷ 栏宽，再夹到 0.75～1.75 ——
  和 `A+` 用同一对上下限，否则「适应窗口」能到的倍率手动按 `A+` 到不了，接着按一下会突然跳。
  宽度量不到（面板还没布局、`ref` 为空）时返回 1，**原地不动**，绝不把正文搞成 0 号字。

手工验收清单（改完 UI 照这个过一遍，两档主题都要看）：

- [ ] **明暗主题**：`--dsw-static-*` 纸底在浅色/深色下都不透底，正文、表格边框、公式块对比度正常。
- [ ] **三档窄面板 320 / 420 / 560px**：`.sa-reading`、`pre`、表格都不出横向滚动条；
      表格自己有 `overflowX:auto`、公式块 `overflow:auto`，窄到 320px 时是「块内滚动」而不是整页横滚；
      560px 那档容器查询会切到 `max-width:100%` 的标题字号。
- [ ] **换讲义保位置**：打开一章讲义 → 滚到中间 → 切另一个风格（C → C2），正文不白闪、滚动位置不跳。
- [ ] **专注阅读进出**：进专注后 `Esc` / 「退出专注阅读」回到原位，倍率与字号读数不变；打印时标题栏与缩放按钮隐藏。
- [ ] **字号一致性**：连按 `A+`，标题、段落、列表、表格、公式一起变大；按 `100%` 全部回原样；
      窄窗口按 `适应窗口` 变小、超宽窗口按它变大（封顶 1.75）。

### 资料树与统一阅读面（W3a / W3b / W6，2026-10-30）

**统一阅读面（W3a）**：资料页和知识点页原来各写一份正文卡，现在都走同一个 `MaterialReadingCard`
（`client.full.js` 里紧挨 `MaterialReading` 的普通渲染函数）。只合并「视图」不合并「状态」：
`detail` / `openPath` 与关闭、切页回调仍由各自页签持有；pending「读取中…」、truncated「已截断」、
error 四类文案、页按钮高亮、`MaterialReading` 排版全部原样保留。

**资料树（W3b）**：资料页的平铺长列表改成「学科 → 路径文件夹 → 文件」可折叠树。

- 分组只从 `资料索引.json` 每条 `path` 的目录段派生（如 `数电/作业/…` → 文件夹「作业」），
  **不改 schema、不加文件夹字段**；`kind` 只作类型 pill 辅助；没有目录段的文件统一进「其他」，不丢文件。
- 悬停（`title`）只显示元信息：类型 · 页数（`ocr.pages` 或已取页数）· 更新时间（`ocr.updatedAt`）。
  摘要目前没有字段，留空、不编造（决策 D-W3-1）。
- 搜索框只筛**文件名 + 科目**（纯前端）；不做路径关键字、不做全文检索（决策 D-W3-3 / F2）。
- 展开状态记在界面记忆 `readMaterialsUi().expand`（`{ [courseId]: 展开的分组键[] }`）：缺省 `{}` = 全部展开，
  坏值自动清洗；返回 / 前进的快照会带上它，切页签回来展开状态还在。

**讲义版本收敛（W6）**：讲义正文上方的版本切换行现在**只列当前生效版**（`styles` + 没有 `supersededBy` 的
`variants`）；被 `supersededBy` 取代的历史版收进「历史 N 版」折叠，默认折叠、点开可回看（不删数据，决策 D-W6-1）。
当前版按钮带 ` · v{version}` 标记（缺省 `version` 时退回旧文案），`model` / `generatedAt` 放悬停提示。
老数据没有 `supersededBy` 时行为等同以前（全部当当前版显示，不报错）。

### 批注：Word 式浮动气泡（F1 / F2，2026-10-31）

**专注阅读标题条不再透正文（F1）**：`.sa-focus-header` 原来是「半透明层 + 负 margin」硬贴，壁纸插件把
`--dsw-alias-bg-layer-1` 调成半透明后，标题条上方 12px、左右 12px 的带子里会透出正文（sticky 只贴到滚动容器的
内容盒，负 `margin-top` 压不上去）。现在改成：专注面 `padding:0 18px 18px`（去掉上内边距，让 sticky 条能贴到
容器顶）+ 标题条用「实色纸底 `--sa-focus-paper-base` + 纸面色 `--sa-focus-paper`」两层不透明底，
`margin:0 -18px 16px` 外扩盖满整条；`@container (max-width:860px)` 里对应改成 `12px`。明暗与玻璃主题都实测过。

**批注主路径改成浮动气泡（F2）**：原文只读，批注内容照旧单独存 `批注.json`（后端契约未变）。

- **拖选即弹**：在正文里选中一段文字（`mouseup`）→ 选区右上角浮出 `position:fixed` 气泡，三个入口
  批注 / 高亮 / 插入段落。气泡 `onMouseDown` 拦掉默认行为（输入框除外），点按钮不会丢选区。
- **定位是纯函数**：`placeAnnotationBubble(rect, viewport, size)` 贴选区右上角，上方放不下翻到下方，
  右侧越界往左收，最后夹在视口内（`margin 8 / gap 6`）；宽度 `min(20em, calc(100vw - 2em))`，320px 窄面板不溢出。
- **失焦即保存**：批注与高亮备注是小输入框、插入段落是多行 textarea，**失焦就提交**（不再有显式「保存」按钮）；
  失败保留草稿并提示「保存失败：…」，成功后 `invalidateAnnotations(file)` 重拉。防重复写盘用 ref 记住上次提交。
- **正文内联标记**：`<mark data-annotation-id>` 画在正文里（高亮有底色、fuzzy 虚线），点标记就地改 / 删
  （`update` / `delete` 都带 `id`）；`insert` 类型不改原文，在锚点段落后长出一块 `.sa-annotation-insert`。
  下方列表与三态徽标（found / fuzzy / lost）、待处理列表、会话内 undo ≤20 步都保留；原常驻工具条降级为兜底入口。
- **同句多命中按序号对齐**：`resolveAnnotationAnchor({body, renderedText, quote, renderedStart})` 取「选区在渲染
  文本里是第几处」去对原文的第几处；两边出现次数不一致时降级 fuzzy（标待确认）而不是锚错位置。
- 样式全部走 `--dsw-alias-*` 令牌、字号用 em（跟着 `--sa-read-scale` 缩放），不写死颜色、不写裸 px 字号。

### 学习记录与交互助手（P3，2026-10-30）

**新页签「记录」**：把「读过 / 批注过 / 标了什么知识点」按时间摊开成时间线，并给一个多轮对话面板。

- **时间线只用现有 JSON 的事实**：`学习记录/阅读位置.json`（读到哪份资料哪一页，打开资料正文时自动记）、
  `批注.json`（写过哪些批注）、`知识点网络.json`（标了什么知识点 / 掌握度），每条都带「来源」标注。
  **不埋点、不统计时长、不编造事件**（决策 E1）。
- **对话归档在磁盘旁**：`学习记录/对话/<courseId>/<safeName>.json` 单会话 + `学习记录/对话索引.json`，
  **不进 `DOC_KEYS`、不进 `/state`、不进备份包**（决策 B3）。写入用「临时文件 + rename」原子写，写前旧文件进
  `学习记录/_backup/`（保留最近 10 份）；不走 `store.writeDocument`。
- **手动注入当前阅读段落**：对话面板上有「让助手读当前阅读段落」按钮，**默认不注入**；点了才把当前页
  （或整份全文，页面取字缺失时）作为 `context` 发给模型。**服务端重读磁盘、不信客户端正文**，硬上限 `6000` 字
  （`lib/study-log.js` 的 `CONTEXT_MAX_CHARS`），超出界面显示「只读了前 N 字」（决策 E1、契约 §5.6）。
- **批注与对话不作为证据回流**：聊天证据只来自当前知识点的题目/资料（`collectExplainEvidence`），
  注入的阅读段落也按「同等资料」对待；`批注.json` 与历史对话**不进**模型上下文（决策 E2）。
- 首版**不做**「总结本章 / 学习建议」这类一次性生成。

接口（`lib/api.js`，均走 `writePreflight` 防跨站）：`GET /study-log`（时间线 + 阅读位置 + 对话索引，
可带 `?courseId=`；`?chat=<id>` 读单条对话全文）、`POST /reading-position`、`POST /assistant/chat`、`POST /study-log/delete`。

## 边界与免责

- **只面向本机自用**：HTTP 接口只监听宿主自己的回环端口，写请求要求自定义头 `X-Study-Request: 1` 且拒绝跨站来源；
  它不是一个可以暴露到公网的服务。
- **网络学堂同步依赖你自己的登录态**：Cookie / 浏览器 profile 都留在你本机，插件不上传任何凭证。
  平台侧接口不是公开 API，平台改版后同步可能失效——这属于已知风险，不是缺陷承诺。
- **不代替你提交作业**：插件只归档「你自己放进 `提交文件/` 的带姓名学号的提交件」，
  不会创建提交件、也不会因为「生成了答案」就把任务标完成。
- **不做后台轮询**：网络学堂同步、讲解生成都是手动触发，避免触发平台反爬与无意义 token 消耗。
- 本项目是个人学习工具，与 DeepSeek / 任何学校教务或网络学堂官方无关；使用需自行遵守所在平台的服务条款。
