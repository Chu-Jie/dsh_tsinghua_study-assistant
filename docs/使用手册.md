## 一、这是什么

一个 DSH 插件。它做三件事，共用同一份数据：

1. **一个面板**（七个页签）——课表、DDL、成绩与 GPA、课程资料、知识点网络。
2. **两个会话工具**——`study_status`（数据健康）、`study_overview`（当前学期 / 今日课程 / 临近 DDL / GPA）。
3. **一条 HTTP 接口**——`/api/study-assistant/*`，面板自己就调它，你也可以用 `curl` 调。

数据全部写成你 `dataDir` 下的 JSON：**可读、可手改、能进 git**。没有数据库、没有云同步、没有运行时 npm 依赖。

## 二、装上之后的位置

| 落点 | 挂载方式 | 内容 |
|---|---|---|
| 左侧栏图标 | `sidebar.panellist`（id = `study-assistant`） | 面板入口 |
| 中央主面板 | `main`（key = `study-assistant`） | 七个页签：今日 / 课表 / DDL / 成绩 / 资料 / 知识点 / 设置 |
| 会话输入框上方 | `conversation.composer.dock` | 临近 DDL 提醒（逾期标红） |
| 右侧栏标签页 | `sidebar.right.pane.tab` + `.title`（标签类型 id `study-assistant/detail`） | 会话详情：概况 / 最近截止；由主面板标题栏的「详情开右侧栏」打开（标题文案是「学习台」，指数据目录那一份数据） |
| 会话工具 | `ctx.tools.register` | `study_status`、`study_overview` |
| HTTP | 一条 `kind: 'prefix'` 路由 | `/api/study-assistant/*`，见 [`接口契约.md`](接口契约.md) |

样式只使用宿主的 `--dsw-alias-*` 主题令牌，跟随明暗主题；不 require 任何宿主客户端包、不用 iframe。
所有请求都走宿主自己的 Web 端口，**插件不另起监听**。

## 三、安装与启用

### 1. 摆进 profile

两种方式，选一种：

**A. `link:`（开发时推荐）**

```bash
cd <你的 DSH profile 目录>
npm install "link:<本仓库绝对路径>"
```

之后改本仓库源码 → **重启 DSH + 刷新页面** 即生效，没有构建步骤。

**B. 用 `cordis.patch.yml` 声明**

仓库根目录的 `cordis.patch.yml` 是装载模板，把它并进 profile 的配置链即可，`config` 段里填你要的配置（见下一节）。

### 2. 重启一次（必须）

宿主进程持有旧的 ESM 模块代，**不会热重载插件主体**。重启后：

- 左侧栏出现「学习辅助」；
- 会话里出现 `study_status` / `study_overview`。

### 3. 确认装对了

```bash
npm run verify:installed     # 直接加载「已装进 profile 的那份产物」跑契约断言
```

它做四件事：配置解析 → `apply()` 注册路由与工具 → 真调两个工具 → 起一个真实 `http.Server` 走接口往返，
外加写入 / 冲突 / 损坏防护的边界断言。**比「界面上看起来有图标」可靠得多**。

> 数据目录初始化失败不会让整个插件不激活：`apply()` 会记一条 error 日志并继续注册工具与路由，
> 让面板还能打开、还能告诉你哪里不对。

## 四、配置

九项，全部有默认值，**装完零配置即可跑**：

| 键 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `dataDir` | string | `$HOME/study-assistant-data` | 数据目录（绝对路径）。默认按用户主目录推导，换机器不用改源码 |
| `backupKeep` | number | `10` | 每份数据文件保留几份轮转备份（`0` = 不留） |
| `locale` | string | `zh` | 界面语言，`zh` / `en` |
| `gpaMode` | string | `4.0-weighted` | 绩点制式，`4.0-weighted` / `5.0-weighted` |
| `studentName` | string | `示例同学` | **必须改成你自己的名字**；听课提醒靠它做点名匹配 |
| `studentNameVariants` | string | 空 | 姓名的其他写法，顿号/逗号/空格分隔 |
| `studentId` | string | 空 | 学号；提交件归档只认「文件名同时含姓名与学号」的文件，**留空＝归档扫描不启用** |
| `workspaceRoot` | string | 空 | 作业工作区根目录（含各学科目录）；留空自动取 `dataDir` 的父目录 |
| `recordingDir` | string | 空 | 腾讯会议录音笔的录像根目录；**留空＝录音导入关闭** |

几个要点：

- **`dataDir` 必须是绝对路径**。写成相对路径会以宿主进程的 cwd 为基准解析——
  那个 cwd 通常不是你以为的地方，结果就是「插件建了一套空数据、界面什么都看不到」。
  （历史上就这么踩过：写成相对路径后数据落到了桌面端的 launch-root 下。）
- **配置写错不会静默吞掉**：`Config` 是一份同步校验 schema，类型不对会返回 `issues`，插件激活失败并在日志里说明哪一项错了。
  枚举项（`locale` / `gpaMode`）写了表外的值同样会被拒。
- **姓名与变体的匹配是「原文精确匹配」**：`studentName: 李雷` + `studentNameVariants: 雷子、小李`，
  语音转写出现「李雷」「雷子」「小李」任一都算叫到你；不会解释正则元字符、不做拼音模糊。
- **`studentId` 留空是刻意的默认值**：归档扫描能不做就不做，只有你填了才启用。

## 五、数据目录

`dataDir` 下是**十一份 JSON** 加三个子目录：

```
<dataDir>/
├─ 学期.json          学期与教学周（/mutate 可改）
├─ 课程.json          课程
├─ 任务.json          DDL 任务
├─ 成绩.json          成绩与 GPA 规则
├─ 作业.json          作业流台账：来源文件指纹、题数、最近一次生成的模型与时间
├─ 资料索引.json      教材 / 课件 / 作业索引（面板只读）
├─ 题目.json          从作业里切出来的题（面板只读）
├─ 知识点候选.json     织网前的候选（面板只读）
├─ 知识点网络.json     节点 + 掌握度 / 重点 / 复习时间 / 证据（/mutate 可改）
├─ 知识点大纲.json     教材目录骨架：章 / 节 / 小节（只读，专用工具写）
├─ 资料分析.json      内容库：详解 / 比方 / 公式 / 易错 / 例题（只读，专用工具写）
├─ 讲解缓存/          按「节点-档位」缓存的讲解 md
├─ 知识画布/          笔记镜像导出（只读视图，可随时重建）
└─ 备份/              写入前的轮转备份
```

### 为什么分成十一份

1. **身份与内容分家**：`知识点网络.json` 存「有哪些点、掌握到什么程度」，`资料分析.json` 存「这个点讲了什么」。
   后者会到 MB 级；混在一起会让每次打开面板都要搬一遍几十 MB。
2. **可手改、可进 git**：都是缩进 JSON，字段名见 [`接口契约.md`](接口契约.md) 第四节。
   但**手改请先退出面板**——面板与手改同时写会触发冲突（见下）。
3. **凭据不在这里**：网络学堂的 Cookie 单独存在 `网络学堂.json`，**不在十一份白名单里**，
   不进 `/state`、不进备份包、不会被 `/reset-doc` 清掉。

### 写入安全（不是「不丢数据」的承诺，而是「坏了能看出来、能退回」）

- **原子写**：写临时文件 → `fsync` → `rename`，不会写出半个 JSON。
- **乐观并发**：每个文档带 `hash`；写请求可带 `expectedHash`，对不上回 `409 conflict`，而不是后写的盖掉先写的。
- **损坏保护**：读到坏文件时**拒绝在上面做增量修改**（`409`），绝不「当作空数据重写」。
- **备份轮转**：每次覆盖写之前，旧版自动进 `备份/`，保留 `backupKeep` 份。
- **每份都过校验**：`validateDoc` 不过就拒写（`422 refuse-invalid:*`）。

> 面板与手改同时进行的唯一安全姿势：先关面板（或至少别在编辑期间点保存）→ 手改 → 再打开面板。
> 冲突时面板会提示，**不要**忽略提示强行覆盖。

## 六、七个页签

### 1. 今日

打开面板的第一屏，从上到下：

- **当前学期与第几周**（没设学期时给一句「去设置里填一个学期」）；
- **今日课程**（按当前节次高亮）；
- **待复习知识点**：掌握度到「精通」的不再提醒，其余**距上次复习满 7 天**才进队列。
  每条都能点开；队列为空时会显示「下一批 X 月 X 日到期」，并给一行「近 7 天复习过 N 个」；
- **临近截止**：逾期标红，按截止时间排序；
- **知识点详解进度**：`已写 / 总数` + 进度条 + 「去写没写的」。

### 2. 课表

按周次展示课程块；支持单双周、指定周次范围。点击课程块看这门课的 DDL 与成绩条目。
学期与教学周起点在「设置」里改，改完这一页立刻跟着重算。

### 3. DDL

- 顶部是**网络学堂同步**（详见 [第八节](#八网络学堂同步)）；
- 任务列表按 学科 / 状态 / 紧急度 筛选，可一键切「只看未完成」「只看逾期」；
- 快捷录入支持相对日期（`明天`、`周五`、`3天后`）与「标题 @ 学科 截止」这种一行式写法；
- 任务状态：`未开始 / 进行中 / 待提交 / 已完成`。**「已完成」由你或归档扫描来改，插件生成的答案不会自动改它。**

### 4. 成绩

- 课程 + 成绩条目 → 加权 GPA；两种制式在「设置」里切；
- 没打分的条目**不计入 GPA**，界面上明确标「未计入」，不会静默当 0；
- 可设目标 GPA，反推「剩下几次作业/考试平均要考多少」。

### 5. 资料

三个视图：

- **教材 / 课件**：按索引列出每份资料的页；
- **正文**：读某一页的正文。电子版 PDF 直接读文字层；扫描件读 OCR 产物（按页取，一次一页）；
- **题目**：从作业里切出来的题，行尾带知识点标签，点标签跳到知识点页签。

资料正文**不接受任意路径**：只认《资料索引.json》里登记过的 `path`，索引外的路径一律 404。
索引里的路径解析后跑出工作区会被拒（`403 escape`）。

### 6. 知识点

这是大板块，不是资料页的附属。资料与知识点**双向联动**：题目行的知识点标签点一下切到知识点页，
知识点卡片里的「看原页」带着 `path` + `page` 切回资料页并打开同一页。

**五个视图**：

| 视图 | 用途 |
|---|---|
| 树（默认） | 有教材大纲的课按 `学科 → 章 → 节 → 小节 → 知识点` 铺开（节点靠 `section` / `subsection` 挂靠）；没大纲的课退回 `学科 → 章 → 知识点`。分支行显示「旗下叶数 / 到熟练数」+ 四档分布条 + `★ 重点数` |
| 导图 | 横向思维导图，圆点**颜色 + 符号**表示掌握度（`○` 未学 / `◔` 学过 / `◑` 熟练 / `●` 精通）。**默认只展开「该复习的章」**，其余收着；手动开合过就按你的选择 |
| 图 | 三列层级图，跟随搜索与筛选结果 |
| 列表 | 按「课程 · 章」折叠的清单，行内四档掌握度 + ★ + 依据数 |
| 讲解 | 已生成的讲解清单，按「课程 › 章」分组，抬头报「已生成 N 份 · 覆盖 X 个节点（还差 Q 个）」 |

**工具条**：课程下拉、搜索（名称 / 别名 / 章名 / **节号 / 小节号** / 备注）、七档筛选
（全部 / 未学 / ★ 重点 / 待复习 / 没归到节 / 有问题 / 没详解）、`命中 N / M`、视图切换、四档掌握度多选。

- 掌握度四颗按钮是**多选筛选**不是图例：勾哪几档只铺哪几档（与七档筛选是「与」关系），勾了出现「四档都要」复位；
- 搜索或筛选非默认时，树与导图**自动全展开**并把命中片段加粗（不然还得一章章点开才看得到命中在哪）；
- 工具条底部一行**体检**：`章号对不上 A · 没归到节 B · 没依据 C · 题目找不到 D [· id 重复 E]`，
  点数字或「挑出有问题的 N 个」直接切到「有问题」筛选。四个计数**可以重叠**；
- 体检行下面是**详解覆盖**「详解：X / Y」，点一下切到「没详解」筛选——下一批该写哪些，按这批往下排。

**节点卡片**能做的操作：

- 改掌握度（四档）、标 / 取消 ★、**今天复习过了**（只写复习时间、不动掌握度）；
- **改位置**（章 / 节 / 小节，三个输入框带 `datalist` 候选，不用背章名）；
- **写备注**（会进搜索）；有详解时直接渲染 `explain / 比方 / 公式 / 易错 / 例题 / 来历`，没写过就明说「未分析」；
- 依据列表（题证据 + 资料页证据），点「看原页」跳资料页。

**批量操作**：一次 `/mutate items` 请求、一次落盘、全成或全不成。
批量标掌握度、批量归位（把命中的 N 个一次挂到同一章/节/小节）、全标 ★ / 取消 ★ / 都打卡。
打卡只写复习时间——「今天翻过了」和「会了」是两件事，整批套同一个掌握度只会把数据弄假。

树里每个**章 / 节 / 小节**分支行右侧有两个入口：`＋`（把这一层预填进「加节点」表单）、
`归位`（先切到这门课、再筛「没归到节」，并把这一层预填进批量归位）。

### 7. 设置

- 学期列表与当前学期、教学周起点；
- GPA 制式、目标 GPA；
- **数据备份**：导出 / 恢复（见 [第十二节](#十二备份与恢复)）；
- 数据文件健康（每份是否存在、字节数、是否损坏）；
- 面板级开关（动效、打印树等）。

> 界面记忆（选中哪个页签、搜索词、筛选、展开到哪个分支、选中哪个节点）只在内存里，**不写盘**；
> 关掉面板或重启宿主就回到默认。

| 工具 | 返回 |

| `study_status` | 数据目录、总体是否健康、十一份文件各自的存在性 / 字节数 / 损坏原因 |

## 八、网络学堂同步

在 DDL 页签顶部：粘一次 Cookie → 预览 → 导入。

### 五条设计取舍（每条都有代价，写在这里免得被当成疏漏）

1. **手动触发，不做后台轮询**——平台没有公开的限流说明，高频轮询有触发反爬的风险；DDL 的时效性以「天」计，手点一次够用。
2. **先预览再导入**——远端作业名与本地课程对不上很常见，把「会导入什么、哪门课没匹配上」摆在确认按钮前，
   比导完再去一堆空科目任务里排查便宜。
3. **去重记号写在任务的 `note` 里**（`[learn:<key>]`），不新增文档字段；删掉记号即等于解绑。
4. **学期由服务端记住**，换学期是一条独立接口——界面**拿不到 Cookie**，所以换学期只能由服务端用它自己的凭证做。
5. **照抄平台的提交状态，且只做单向升级**——平台说「已提交 / 已批改」的行直接落 `done`；
   反方向（本地完成、平台没交）**不动**，因为线下交、课堂交、老师还没登记都可能。
   代价是：你**故意**把一份平台已收到的作业留在待办时，下次同步会把它标回完成。

### Cookie 怎么粘

整条粘（形如 `JSESSIONID=...; XSRF-TOKEN=...`）。平台的页面接口只要 Cookie 就放行，
但数据接口在缺 CSRF 头时一律 403；插件会「先只发 Cookie，被 403 且有 CSRF cookie 就补头重试一次」——
**别依赖重试**，课程列表与作业列表全走需要 CSRF 的那一侧，少一个字段就什么都拿不到。

### 登录态会过期

会话 Cookie 是**服务端空闲超时**；真正长命的是单点登录的「信任浏览器」凭证。
所以正确姿势是：**用一个专用浏览器 profile 持有凭证**，磁盘上的 `网络学堂.json` 只是缓存。
票空了先去浏览器取（面板上有「打开登录窗口」），再回来同步；不要反复重连。
「要人工登录」只是一条**冷却 20 分钟**的封条，期间别把浏览器关掉。

## 九、课堂听课提醒

把课堂音频按片喂给语音识别，实时转写；转写里出现你的姓名时提醒你（点名 / 被提问）。

- **切片**：单片上限 120 秒、下限 0.3 秒。二进制上传走专用的体积上限（约 3.84 MB），
  不复用通用 1 MiB 上限——16 kHz 单声道 PCM 每秒 32 KB，60 秒就 1.92 MB，会被 413 掉，
  而错误信息里只有 `too-large`，看不出是「音频太长」。
- **点名匹配**：`studentName` + `studentNameVariants`，**原文精确匹配**（不解释正则元字符）。
- **去重**：同一句话在滑动窗口内只提醒一次；转写片段有上限，超长会截断。
- **笔记**：课堂笔记按学科写进工作区里对应学科目录；`.learn-edge/` 是专用浏览器 profile，
  两者都在「工作区」侧，不在 `dataDir`。
- **录音导入**：`recordingDir` 留空时整个功能关闭；填了才会去扫录像目录（每场一个子目录）。

听课面板是宿主内的一个工具页，**默认关闭**：
它的「功能未就绪」用 `200 + ok:false` 表达，而不是 503——状态灯要和真正的故障区分开。

## 十、知识点这条线

顺序是固定的：**候选 → 织网 → 大纲 → 挂靠 → 详解 → 讲解 / 问答**。

### 1. 织网（候选 → 节点）

把从课件/教材抽出的候选知识点织成网络：同名（忽略大小写与空白）或别名命中的**合并**，否则新建节点；
只补空字段（课程 / 章 / 节），**不覆盖**已有掌握度、重点与备注；证据按 `type+id` 或 `file+page+quote` 去重。
网络文件损坏时返回 `409` 并**拒绝织网**（不覆盖）；候选为空也照常 200（统计全 0）。

### 2. 大纲（教材目录 → 章/节/小节）

教材目录页解析成第 10 份文档。写入口**只有** `npm run knowledge:outline`：

- 默认 **dry 预览**（只打印解析出几章几节几小节、与磁盘差多少），`--apply` 才写盘；
- 新的解析结果比磁盘少一半以上会**拒绝写盘**（防 OCR 半残时手滑覆盖）；
- `--apply` 默认是**合并**：同 `courseId` 原位替换、其它课原样保留；真要「只剩这门课」才加 `--replace`；
- 面板里**改不了大纲**（`/mutate` 对它回 `use-dedicated-route`），改大纲就是重跑脚本。

节点挂靠规则：`section` 去掉 `§` 前缀后对到节、`subsection` 对到小节；
节号对不上进「没归到节」，章号对不上进「章号对不上」，没有大纲的课整门退回老树。

### 3. 详解（`资料分析.json`）

每个知识点预先生成：详解、打个比方、公式（tex + 白话）、易错、例题（题干 + 步骤 + 答案 + 套路）、来历（文件 + 页码 + 原文）。
**详解不是点了才生成**，而是提前算好落盘、点开秒看。

写入口是 `npm run analysis`：`--merge <patch.json> [--apply]` 原位合并，`--validate` 分级报错（有 error 拒绝写盘），
`--create-nodes` 会在 patch 里出现新知识点时自动建节点（id = `k_` + `课程id|节号|标题` 的 hash 前 10 位，
同一节同一标题永远同一 id，重跑不造重复；**先建节点、成功后才写详解**）。写盘走数据层，旧版自动进 `备份/`。

> 详解（`资料分析.json`）与「讲解」（`讲解缓存/`）是**两套东西**：前者是提前算好的内容库，
> 后者是现场调模型生成的三个档位。所以介绍里会分开数「有详解 X · 只有旧讲解 Y · 都没有 Z」。

### 4. 讲解（三种档位）

| 档位 | 内容 |
|---|---|
| `assistant`（助教推导，默认） | 从定义讲到例题的完整推导 |
| `exam`（考前速通） | 只留考点、结论、易错 |
| `hint`（只给提示） | 不给答案，只给思路与第一步 |

- `GET` 读缓存（命中即回，不烧 token），`POST` 现场生成一档并写 `讲解缓存/<节点id>-<档>.md`（带 frontmatter）；
- 只有 `force:true` 才跳过缓存重生成；
- 生成较慢（单档通常 10–40 秒），模型偶发空回复会回 `502 llm-empty-response`，**重试即可**，不是接口坏了；
- 缓存超过 200 KB 会截断并在响应里标 `truncated`；节点已不在网络里的缓存**不删**，只标 `stale`。

### 5. 问答

围绕**当前节点**的问答：每轮都重跑该节点的证据收集与摘要（证据上限 6000 字），拼成「资料片段 + 对话」交给模型。

- 一次最多 **20 条消息**、单条最多 **2000 字**、最后一条必须是 user；
- **不落盘、不缓存**——同一句在不同轮次本来就该有不同答案；
- 返回里带 `sources`（最多 6 条）与证据统计，便于判断它是「有依据」还是「在编」。

### 6. 导出与体检

- `npm run kp-notes:export`（或面板「导出」）把网络与题目导出成笔记工具能认的 md 目录（`知识画布/`），
  幂等、只删上一份 manifest 登记过的文件，**可随时重建**；
- `npm run knowledge:audit` 只读检查「挂靠看起来对、实际挂空」——章名差一个字掉进「章号对不上」、
  依据指向不存在的题号这类面板不会报错的问题（`--strict` 给 CI 用）；
- `npm run analysis:validate` 检查内容库缺标题 / 缺详解 / 缺来历 / 知识点不在网络里等问题。

## 十一、提交件归档

**一条 DDL 任务被标成「已完成（归档）」的唯一判据**：
你本人把「文件名同时含姓名与学号」的提交件放进了 `<学科>/提交文件/`。

- 判据由宿主侧扫描执行：扫各学科目录，命中才把对应任务置 `done`；
- 文件名**同时含**姓名与学号即可，顺序无关；规范命名示例：`示例同学_2025000000_数据结构第3次作业.pdf`；
- **匹配唯一才归档**；匹配不唯一、课程对不上、文件名缺姓名或学号时，只在结果里列出原因（`findings[]`），
  不动任务状态，让你自己判断；
- 只做「同一份件不要重复归档」的记号，**不删除、不改任务标题与截止日**，也**不做反向撤销**；
- **agent 生成答案 ≠ 归档**。答案只写进 `<学科>/答案/`；`提交文件/` 归你。

如果不想用这个功能：把 `studentId` 留空（默认就是空），整个归档扫描不启用。

## 十二、备份与恢复

### 导出

`GET /backup/export` 把十一份文档打成一个包（面板「设置 → 数据备份」用的就是它）：

```json
{
  "format": "study-assistant.bundle",
  "version": 1,
  "exportedAt": "…",
  "docs":    { "term": {…}, "courses": {…}, "…": {} },
  "hashes":  { "term": "sha256:…", "…": "sha256:…" },
  "checksum": "sha256:…"
}
```

- **只读**，无参数；缺失/损坏的文档跳过并记进 `skipped[]`；
- `checksum` 对 `docs` 的**键排序规范 JSON** 求值，所以手工调整键序不影响校验；
- `网络学堂.json`（凭证）**不在白名单里**，不会被导出。

### 恢复

顺序是死的：**校验和 → 包格式 → 逐份 `validateDoc` → 全合法才开写**。
任一份不合法 → `400` 且**一个字节都不写**（`checksum-mismatch` / `invalid-doc` / `bad-format` / `bad-version` …）。
通过后逐份覆盖写回，写前旧版自动进 `备份/`。

**刻意不回滚**：先验后写已经堵死「坏包写半截」；再把已写的往回滚，反而会覆盖掉更新的内容。

### 三条保命习惯

1. 大改动前先导出一次包（或整目录 `cp`），存到 `dataDir` 之外；
2. 手改 JSON 前把要改的文件复制一份；
3. 恢复后立刻看 `study_status` 的十一份健康状态。

## 十四、常见问题

**打开面板是空白 / 报 `undefined`、`NaN`**
先跑 `npm run panel:smoke -- --data <你的 dataDir>`：它用真实数据把面板渲一遍，能直接指出哪份数据长得不对。
常见原因是手改 JSON 时字段类型写错（如 `null` 混进 `nodes[]`）。

**面板显示「未连接」/ 取不到数据**
数据目录初始化失败时插件仍会注册路由，用 `study_status` 看 `dataDir` 是不是你期望的那个；
`dataDir` 写成相对路径是最常见的原因。

**写保存时提示冲突（409）**
有另一处（另一个宿主窗口、手改、脚本）刚写过同一份文档。刷新面板重取 `hash` 再保存，
**不要**忽略提示重试覆盖。

**网络学堂同步 403 / 什么都拿不到**
Cookie 不完整（缺 CSRF）或登录态过期。整条重粘；仍不行就「打开登录窗口」重新取票。
另外注意：两个宿主如果指向同一个 `dataDir`，**不要在其中一个里改数据**——后写的会盖掉先写的。

**讲解生成报 `502 llm-empty-response`**
模型偶发空回复，重试即可。报 `503 llm-unavailable` 则是宿主没挂模型接口，属于环境问题。

**上传音频报 `413 too-large`**
单片超过 120 秒或体积超限。客户端应自己切片；`too-large` 只说明超限，不区分「音频太长」还是「请求体太大」。

**POST 报 `403 need-request-header` / `cross-site-rejected`**
写请求必须带 `X-Study-Request: 1`，且不能来自跨站页面。用面板走不会有这个问题，自己写脚本时容易忘。

**改了源码但界面没变**
宿主不会热重载插件主体：**重启宿主 + 刷新页面**。只改 `client.js` 且启用了客户端热重载时才可能免刷新。

## 十五、边界与已知限制

- **只面向本机自用**：接口只监听宿主自己的回环端口，不适合暴露到公网。
- **不做后台轮询**：同步与生成都手动触发。
- **不做云同步 / 多端互斥**：两个宿主指向同一 `dataDir` 时靠乐观并发冲突挡，挡不住「人为忽略提示」。
- **网络学堂不是公开 API**：平台改版后同步可能失效；同步结果只做单向状态升级。
- **`知识点大纲` 与 `资料分析` 不能在面板里改**：只能由专用工具整份落盘，这是为了避免面板把手写内容冲掉。
- **讲解缓存不会自动删**：节点从网络里消失后缓存只标 `stale`，清理需要你自己来。
- **中文路径**：Windows 上路径含中文通常没问题，但给脚本传路径务必带引号、用绝对路径。
